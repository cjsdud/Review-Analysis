# 리뷰핏 샘플 리포트

> 실제 셀러에게 보여드리는 “리뷰핏이 만들어주는 결과 예시” 입니다. 본인의 리뷰 파일을 올리면 상품명·리뷰·별점에 맞춰 결과가 자동으로 달라집니다.

## 이 리포트는 무엇인가

- 패션 쇼핑몰 리뷰 데이터를 기반으로 **상품별 반복 불만**과 **상세페이지 수정안**, **CS 답글 초안**을 자동으로 정리한 샘플 리포트입니다.
- 실제 셀러 파일을 업로드하면 상품명·리뷰 내용·별점·옵션에 맞춰 결과가 달라집니다.
- 이 샘플은 `sample-data/sample_reviews_fashion.csv`(116개 리뷰 / 14개 상품) 기준입니다.

## 이번에 먼저 고칠 상품 TOP 3

**“이 3개부터 손대시면 효과가 빠릅니다.”**

### 1. 린넨 와이드 팬츠

- 전체 리뷰 **12** / 부정 리뷰 **6** / 개선 이슈 발견 리뷰 **11**
- **핵심 문제**
  - 허리가 작게 나옴 (3건, 25%)
  - 기장이 김 (2건, 17%)
  - 실물 색상이 화면보다 어두움 (2건, 17%)
- **근거 리뷰 (실제 고객 코멘트)**
  > “허리가 너무 껴서 불편하고 원단도 얇아서 비침이 심해요. 환불하고 싶어요.”
  > “기장이 길어서 단 수선 맡겼어요. 키 작은 사람은 참고하세요.”
  > “화면에서는 밝은 카키였는데 실물은 훨씬 어둡고 칙칙해요.”
- **상세페이지 수정안**
  - 사이즈표 상단에 `허리가 작게 나오니 한 치수 큰 사이즈를 권장합니다` 안내 추가
  - 모델 키와 착용 기장을 표기하고, 키별 가이드(예: 160/170) 추가
  - 자연광·실내 조명별 색상 비교컷 추가
- **CS 답글 예시**
  > 안녕하세요 고객님, 소중한 후기 감사합니다. ‘허리가 작게 나옴’ 관련해 불편을 드려 죄송합니다. 사이즈 정보를 더 정확하게 안내드리도록 상세페이지를 보완하겠습니다.

### 2. 오버핏 반팔 티셔츠

- 전체 리뷰 **10** / 부정 리뷰 **4** / 개선 이슈 발견 리뷰 **8**
- **핵심 문제**
  - 원단이 얇고 비침이 있음 (2건, 20%)
  - 실물 색상이 화면보다 어두움 (1건, 10%)
  - 세탁 후 보풀이 생김 (1건, 10%)
- **근거 리뷰**
  > “흰색은 비침이 너무 심해요. 원단이 얇아서 속옷이 다 비쳐요.”
  > “화면보다 실물이 더 어두운 블랙이에요. 거의 먹색.”
- **상세페이지 수정안**
  - 비침 정도와 이너 권장 여부, 원단 두께를 상세페이지 상단에 명시
  - 비침 테스트 컷(빛 비춘 사진) 추가
  - 보풀 관리법과 세탁 주의사항(뒤집어 세탁 등) 안내
- **CS 답글 예시**
  > 안녕하세요 고객님, 후기 감사합니다. 비침에 대한 안내가 부족했던 점 죄송합니다. 소재와 두께 정보를 더 상세히 기재하겠습니다.

### 3. 데님 자켓

- 전체 리뷰 **10** / 부정 리뷰 **5** / 개선 이슈 발견 리뷰 **7**
- **핵심 문제**
  - 무게가 무거움 / 착용감이 답답함
  - 마감 상태가 미흡함 (단추 주변 실밥)
  - 세탁 시 물빠짐
- **근거 리뷰**
  > “데님이 너무 무겁고 뻣뻣해서 어깨가 답답해요. 착용감이 불편합니다.”
  > “단추 주변 실밥이 엄청 튀어나오고 안감이 뜯어져 있었어요.”
  > “세탁하니 물빠짐이 심해서 다른 옷에 묻었어요.”
- **상세페이지 수정안**
  - 무게(g) 표기 + 봄가을용임을 명시
  - 출고 전 실밥·안감 검수 항목 강화
  - “첫 세탁은 단독·찬물 세탁 권장” 안내 추가
- **CS 답글 예시**
  > 안녕하세요 고객님, 진심으로 죄송합니다. 검수 과정을 강화하고, 원하시면 교환·반품을 바로 도와드리겠습니다.

## 리포트 해석 시 주의사항

- 리뷰핏은 고객 리뷰에서 **반복되는 표현**을 기반으로 개선 포인트를 제안합니다. 한두 건의 의견을 일반화하지 않도록 빈도/비율을 함께 표시합니다.
- 실제 상세페이지 수정 전에는 **상품 특성·재고·배송 정책·교환/반품 정책**을 함께 확인해야 합니다.
- 리뷰핏의 제안은 **최종 판단이 아니라 셀러의 의사결정을 돕는 참고 자료**입니다.
- 분석 결과의 분류가 어색해 보일 때는 상품 상세 화면에서 **‘분류 수정’** 버튼으로 직접 고칠 수 있고, 그 수정은 **다음 분석에도 자동으로 반영**됩니다.
