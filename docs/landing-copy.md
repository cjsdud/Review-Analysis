# 리뷰핏 (ReviewFit) — 홍보/모집 카피 모음

> 무료 진단 모집·DM·랜딩페이지에 바로 가져다 쓸 수 있도록 정리한 카피 모음입니다.
> **메시지 톤 원칙**: “AI 리뷰 분석툴”을 전면에 내세우지 말 것. **“리뷰 엑셀을 상품 개선 리포트로 바꿔드린다”** 가 메인.

---

## 1. 서비스 한 줄 소개

> **“리뷰 엑셀만 올리면 상품별 반복 불만과 상세페이지 수정안을 자동으로 정리합니다.”**

대안 카피:

- 리뷰 1,000개를 한 번에 읽고 정리해드립니다.
- 부정 리뷰만 모아 ‘먼저 고칠 상품 TOP 3’를 골라드립니다.
- 상세페이지 수정안과 CS 답글 초안까지 한 번에.

---

## 2. 문제 제기 문구 (랜딩/광고용)

상황 공감형 한 줄들:

- 리뷰는 쌓이는데 **어떤 상품을 먼저 고쳐야 할지** 모르겠다면
- 부정 리뷰를 **하나씩 다 읽기엔 시간이 너무** 오래 걸린다면
- **상세페이지를 어떻게 수정해야 할지** 막막하다면
- 같은 컴플레인 답글을 **매번 새로 쓰는 게 지친다**면
- ChatGPT에 리뷰를 일일이 복사·붙여넣기 하는 게 **번거롭다**면

---

## 3. 무료 진단 모집 문구 (커뮤니티 게시글용)

> 🔽 아래 본문을 그대로 복사해 게시판/오픈채팅/네이버 카페에 올리세요.

**제목**

> 패션 쇼핑몰 리뷰 엑셀, 무료로 진단해드립니다 (베타 셀러 10분 모집)

**본문**

```
안녕하세요. 패션 쇼핑몰 리뷰 데이터를 받아서
상품별 반복 불만과 상세페이지 수정안을 자동으로 정리해주는
베타 서비스를 만들고 있습니다.

리뷰가 50개 이상 쌓인 의류/패션 셀러 10분께
무료로 ‘리뷰 진단 리포트’를 만들어드립니다.

분석해서 드리는 결과 예시:
- A상품: 허리가 작다는 리뷰가 반복 → 상세페이지에 한 치수 업 권장 문구 추가 제안
- B상품: 화면보다 색상이 어둡다는 의견 반복 → 자연광/실내 조명별 색상 비교컷 제안
- 상세페이지에 추가할 문구 추천
- 부정 리뷰에 보낼 CS 답글 초안 (기본/정중/친근 3종)

진단에 필요한 것:
- 스마트스토어 / 카페24 / 쿠팡 / 자사몰 어디서 받은 리뷰 파일이든 OK
- 형식은 CSV 또는 엑셀(XLSX)
- 필요한 컬럼은 상품명 / 별점 / 리뷰 내용 (그 외는 있어도 없어도 됩니다)

개인정보:
- 주문번호 / 전화번호 / 이메일은 분석 전에 자동으로 가립니다.
- 분석에는 상품명 / 별점 / 리뷰 내용만 있으면 됩니다.
- 민감한 정보는 업로드 전에 미리 지우셔도 좋습니다.

신청은 댓글 또는 DM으로 연락 부탁드립니다. 짧은 소개(어떤 쇼핑몰을 운영하시는지, 대략 리뷰 개수)만 같이 주시면 됩니다.

진단 리포트는 며칠 안에 PDF/링크로 보내드립니다.
```

혹시 무료 진단 리포트를 한 번 받아보실 의향이 있으실까요?

상품명 / 별점 / 리뷰 내용만 있으면 분석 가능하고,

혹시 컬럼이 다르더라도 자동으로 맞춰드립니다.

## 5. 개인정보 안내 문구 (랜딩 하단/모집 글 하단)

> ✅ **읽는 분이 안심할 수 있도록 신뢰 톤으로** 작성된 안내입니다.

- 주문번호·전화번호·이메일·주소는 **업로드 후 자동으로 가립니다**. (원본 파일은 서버 디스크에 저장하지 않습니다.)
- 분석에는 **상품명·별점·리뷰 내용**만 있어도 충분합니다.
- 민감한 정보가 걱정되면 **업로드 전에 해당 컬럼을 미리 지우셔도** 됩니다.
- 파싱된 데이터는 일정 시간이 지나면 자동으로 비워지는 구조를 사용합니다(`UPLOAD_ROWS_TTL_MIN`).
- 분석 결과(상품별 이슈 요약)는 셀러님 본인이 다운로드 받을 수 있고, 외부에 공유하지 않습니다.

## 7. 사용 금지 표현 (피해야 할 톤)

UI/홍보 카피에서 피할 표현:

| 피할 표현 | 대안 |
|---|---|
| AI 리뷰 분석툴 | 리뷰 기반 상품 개선 리포트 |
| 머신러닝 / 딥러닝 | 자동 분류 |
| LLM | AI (꼭 필요한 경우만) |
| classification / normalized / raw data | 리뷰 분류 / 공통 형식 / 업로드 데이터 |
| confidence score | 매칭 신뢰도 |
| “AI가 해결해드립니다” | “셀러가 바로 고칠 수 있게 정리해드립니다” |

리뷰핏의 차별점은 **‘분석해드린다’가 아니라 ‘셀러가 할 일을 정해드린다’** 입니다. 이 톤을 모든 카피에서 유지하세요.
