## 2. 업로드 / 분석

- [ ] 실제 셀러 엑셀(스마트스토어/카페24/쿠팡 중 1개 이상) 업로드 → 컬럼 자동 매핑 정확도 확인
- [ ] 작성일 컬럼이 **있는** 파일 → 기간별 리뷰 변화 섹션 정상 (Pro+ 계정)
- [ ] 작성일 컬럼이 **없는** 파일 → 전체 분석은 정상 + 기간 섹션만 빈 상태 안내
- [ ] 분석 진행률이 25%에서 멈춰 보이지 않고 단계 문구("리뷰 반응을 분류하고 있어요" 등)가 갱신됨
- [ ] completed → "리포트 보기" → 대시보드 정상 렌더 (빈 화면 X)
- [ ] 상품 상세 → 핵심 문제 카드 → 근거 리뷰 → 관련 리뷰 모달 (마스킹 확인: 전화번호/이메일/주문번호 가려짐)
- [ ] 반복 이슈 차트 클릭 → 해당 카테고리 리뷰 모달 (빈 모달 X)
- [ ] CS 답글 초안 — 5개 톤 탭 전환 시 실제 다른 문체 답글 + 같은 톤 재클릭 시 재요청 없음
- [ ] CS 답글에 `size_fit` 같은 내부 키 / issueLabel 원문 따옴표 인용이 노출되지 않음
- [ ] 긍정 리뷰 기반 답글에 불필요한 "죄송합니다" 없음
